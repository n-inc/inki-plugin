# AI エージェント向けのインキの plugin

[English](README.md)

[インキ](https://inki.so) は、仕上げたい文章（記事、報告書、提案書、プレスリリース）を書くためのアプリです。下書きはノートとして置きます。インキのチェックはノートを段落ごとに読み、誤字、文法の誤り、読みにくい文に印を付けます。ノートは Web、Mac、iPhone、Android のインキで直せます。

この plugin を入れると、Claude Code や Codex などの AI エージェントが、あなたのインキのノートを一緒に仕上げます。エージェントをあなたのインキのアカウントにつなぎ、文章の決定権をあなたに残す進め方を教えます。

1. 会話の中の下書きを、インキのノートに入れる
2. ノートにインキのチェックをかける
3. 指摘を 3 つに分けて見せる。直すもの、そのまま残すもの（理由を添える）、あなたにしか答えられないもの（足りない数字や出典など）。最後のものを推測で埋めない
4. 頼まれた分だけ直す
5. あなたがインキでノートを直したら、先にその直しを読んで保ち、あなたの版から続ける

どこからでも頼めます。たとえば次のように頼みます。

- 「このプレスリリースの下書きをインキに入れて、チェックして、誤字を直して」
- 「新製品の発表のノートをチェックして」
- 「インキで下書きを直したので、続けて」

## 入れ方

インキのアカウントが要ります。[inki.so](https://inki.so) で作れます。

### Claude Code

```
/plugin marketplace add n-inc/inki-plugin
/plugin install inki@inki
```

続けて `/mcp` を開き、`inki` を選んで、開いたブラウザでインキにサインインします。

### Codex

```
codex plugin marketplace add n-inc/inki-plugin
codex plugin add inki@inki
codex mcp login inki
```

開いたブラウザでインキにサインインし、Codex の新しいセッションを始めます。

### ほかのエージェント

この plugin は、ほかのエージェントでも使える 2 つの部品でできています。

- インキの MCP サーバー `https://inki.so/api/mcp`。OAuth でサインインするリモートの MCP サーバーを足せるエージェントなら、どれでもつなげます
- skill [`skills/inki-notes/SKILL.md`](skills/inki-notes/SKILL.md)。Agent Skills を読むエージェントは、そのまま読み込めます

## エージェントがあなたのアカウントでできること

サインインすると、エージェントは次のことができます。ノートとフォルダを探して読む、アカウントの名前とメールアドレスを見る、ノートを作って直す、ノートの名前を変えて移す、フォルダを作る、ノートを 1 つずつインキのゴミ箱に移す（30 日のあいだ戻せる）、インキのチェックとレビューをかける、自分の直しを取り消す。インキは直す前の版をノートの履歴に残すので、元に戻せます。エージェントの権限の設定によっては、直すたびにあなたに確かめます。

チェックした段落は、インキのアプリと同じく、プランの 1 時間あたりの上限に数えます。レビューはインキのアカウントのクレジットを使います。エージェントから送ったノートは、インキの[プライバシーポリシー](https://inki.so/ja/privacy)と[利用規約](https://inki.so/ja/terms)のもとで扱います。

つなぐのをやめるときは、インキの「設定 › アカウント › 連携サービス」を開きます。

## この repository にあるもの

| 場所 | 役目 |
| --- | --- |
| `.mcp.json`、`mcp.json` | インキの MCP サーバー `https://inki.so/api/mcp`（Claude Code は `.mcp.json`、Codex は `mcp.json` を読む） |
| `skills/inki-notes/SKILL.md` | エージェントがあなたとノートを書き、チェックし、直し、続ける進め方 |
| `.claude-plugin/`、`.agents/plugins/`、`plugin.json` | Claude Code と Codex 向けの設定 |

plugin にはスクリプトが無く、エージェントがサーバーにつなぐためのサインインの情報のほかは、あなたのコンピューターに何も保存しません。
